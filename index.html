How to Install

Get Started in Minutes

Follow these simple steps to install the DungeonSelect modpack and begin your adventure.

1

Download the Package

Download the DungeonSelect .zip from our download section.

The package includes the mod and Fabric installer for Minecraft 1.21.11
2

Install Fabric

Extract the .zip and run the Fabric installer. Select Minecraft 1.21.11 when prompted.

Make sure to select the correct Minecraft version
3

Install the Mod

Place the DungeonSelect .jar file from the extracted folder into your mods folder.

Or press Win+R and type %appdata%\.minecraft\mods
4

Launch Minecraft

Open the Minecraft Launcher, select the Fabric profile, and click Play!

Make sure you have enough RAM allocated (4GB+ recommended)
